# Технические заметки и подводные камни

## Стек и почему он такой

| Слой | Выбор | Почему |
|---|---|---|
| Фронт | Preact + htm + Vite + официальный `telegram-web-app.js` | API как у React, ~5 КБ вместо ~45, без JSX и плагинов; работает даже без сборщика (см. tools/build-preview.mjs) |
| Бэкенд | Node + Hono + grammY, **один процесс** (API + вебхук бота + статика + воркер напоминаний) | один деплой, одни логи, ноль межсервисной возни |
| БД | Postgres (Neon или Supabase, бесплатный тариф) через `postgres` | jsonb для состояния, транзакции `for update` против гонок |
| Логика | `shared/` — чистые функции без I/O, общие для клиента и сервера | тестируется без базы, баланс правится в одном файле |
| Хостинг | Railway, Fly или VPS за €5 (Hetzner) — **always-on** | у serverless холодный старт; на `pre_checkout_query` всего 10 секунд |

## Подводные камни

### Платежи Stars
- Валюта `XTR`, `provider_token` пустой. Ссылку создаёт `createInvoiceLink`, на клиенте её открывает `WebApp.openInvoice`.
- На `pre_checkout_query` нужно ответить **за 10 секунд**, иначе платёж отменяется. Там только быстрые проверки, без тяжёлой логики.
- Выдавать товар **только** по `successful_payment`, а не по колбэку `openInvoice('paid')` на клиенте: клиенту не доверяем.
- Идемпотентность: `telegram_payment_charge_id` — первичный ключ в `payments`. Telegram может прислать апдейт повторно.
- Возврат: `refundStarPayment(user_id, charge_id)`. Стор тоже может вернуть деньги в течение 21 дня и списать Stars с твоего баланса.
- Деньги: $0.013 за Star, холд 21 день, вывод от 1000 Stars через Fragment в Gram (TON). Нужен TON-кошелёк и облачный пароль (2FA) на аккаунте владельца бота.
- Цифровые товары внутри Telegram продаются **только** за Stars. Не ставь ссылок на внешнюю оплату: это нарушение правил Telegram и сторов.

### Хранение прогресса
- Истина — только на сервере. `initDataUnsafe` с клиента не используется никогда, только `initData` с HMAC-проверкой (`server/src/auth.ts`).
- Время — только серверное. Состояние пересчитывается лениво от `lastTickAt` (`advance()`), никаких cron-задач по каждому бойцу. Перевод часов на телефоне ничего не даёт.
- Бой детерминирован (сид = id бойца + номер боя), поэтому исход нельзя перекрутить повторным запросом.
- `localStorage` и `CloudStorage` годятся только для UI-флагов («уже спрашивали write access»).

### Бот и напоминания
- Писать можно только тем, кто нажал /start или дал согласие через `requestWriteAccess()` (Bot API 6.9+). Каркас просит разрешение при первом открытии.
- Лимиты: около 30 сообщений в секунду суммарно и не больше 1 в секунду в один чат. При 429 ждать `retry_after`. Воркер шлёт пачками по 25 штук с паузой.
- Блокировка: 403 на отправку и апдейт `my_chat_member` со статусом `kicked`. Помечаем `bot_blocked` и больше не пишем.
- Таймзона приходит с клиента (`getTimezoneOffset`) при каждом открытии, по ней считаются тихие часы.

### iOS, Android, Desktop
- iOS: свайп вниз сворачивает Mini App, его отключает `disableVerticalSwipes()` (7.7+). Safe area: `env(safe-area-inset-*)`, а в fullscreen — `contentSafeAreaInset`.
- Android: старые WebView. Не использовать свежий CSS без фолбэков, проверять на дешёвом устройстве.
- Desktop: нет хаптиков, другой размер окна. Вёрстка в одну колонку с `max-width`.
- `structuredClone` нет в старых Android WebView — состояние клонируется через JSON.
- `localStorage` может быть недоступен (песочница) — обёртка `web/src/storage.ts` падает в память.
- Шрифты тем грузятся с Google Fonts; при плохой сети первые секунды будет системный шрифт (`display=swap`).
- Перед вызовом новых методов проверять `isVersionAtLeast` (так сделано в `web/src/telegram.ts`).
- Для теста в Telegram нужен https: `cloudflared tunnel --url http://localhost:5173`, этот URL указывается в @BotFather как адрес Mini App.

### Безопасность и масштаб
- Дешёвые накрутки не страшны: экономика на сервере, валюты для фарма нет.
- При росте: вынести воркер напоминаний в отдельный процесс, добавить индекс по `events(created_at)` и партиционирование.
